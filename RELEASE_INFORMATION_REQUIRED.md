# Release Information and Remaining Store Inputs

The web repository and GitHub Pages deployment use these public values:

- Maintainer: `thelandofgrub`
- Website: `https://thelandofgrub.github.io/course-compass/`
- Repository: `https://github.com/thelandofgrub/course-compass`
- Support: `https://github.com/thelandofgrub/course-compass/issues/new`
- Account deletion: `https://thelandofgrub.github.io/course-compass/legal/delete-account.html`
- Security reporting: `https://github.com/thelandofgrub/course-compass/security/advisories/new`

The following store and native-release values still require product-owner decisions or accounts:

- Developer legal name and any postal address required by the selected stores or jurisdictions
- A monitored private support email if a store requires email rather than the public support URL
- Final bundle/application identifiers and store SKU
- Countries/regions of distribution and minimum player age
- Whether email/password accounts will be offered at launch or anonymous sync only
- Authorized production domain in Firebase Authentication
- Store developer accounts, signing identities, certificates, and private signing keys

Signing secrets must never be committed. Complete the remaining store-specific fields before native store submission; they do not block source upload or GitHub Pages publication.
