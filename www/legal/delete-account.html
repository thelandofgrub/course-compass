CourseCompass

Delete your account and data

In the app

  1. Open CourseCompass and select Settings.
  2. Select Privacy & Location.
  3. Export a backup if wanted.
  4. Select Delete cloud account and confirm.
  5. Select Delete local data if you also want to clear this device.

Cloud deletion removes the current user’s portable data and authentication account. Local deletion clears CourseCompass data on the current device. Group data that belongs to another host may remain under that host’s control.

If you cannot access the app

Open a support request on GitHub without posting an email address, account identifier, private group code, or location data. A maintainer can provide appropriate next steps. Anonymous accounts cannot reliably be matched without the original device or session.
